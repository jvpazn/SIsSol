> Um sistema prático para formalizar e gerenciar pedidos de manutenção e TI, eliminando a desorganização de solicitações informais.

---

## 📋 Sobre o Projeto

Muitas instituições sofrem com pedidos de suporte feitos "de boca" ou por mensagens soltas, o que gera esquecimento e falta de controle.

Este projeto visa resolver esse problema centralizando tudo em uma plataforma onde os colaboradores podem abrir chamados e a equipe técnica pode gerenciá-los de forma eficiente.

## 🚀 Funcionalidades Principais

* **📝 Abertura de Chamados:** Interface para registrar solicitações detalhando o problema (TI, Manutenção Predial, etc).
* **👀 Acompanhamento em Tempo Real:** O solicitante pode ver se o chamado está "Pendente", "Em Andamento" ou "Concluído".
* **👨‍💻 Histórico de Solicitações:** Registro completo de todos os pedidos antigos para fins de auditoria e controle.

## 🛠️ Tecnologias Utilizadas

* **Linguagem:** JavaScript
* **Framework:** React Native
* **Gerenciamento de Dependências:** npm
* **API:** REST API desenvolvida em Java + Spring Boot

### Pré-requisitos

* **Node.js 18 ou superior**
* **npm**
* **React Native** configurado no ambiente de desenvolvimento
* A **API Spring Boot** deve estar em execução para que o aplicativo consiga realizar as requisições.
